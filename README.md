# 智能抽帧生产 V1.1

智能抽帧生产任务的 React + Vite 交互原型，发布版本日期为 2026-10-27。

列表按批次折叠，首行底色稍深、展开行更浅。列顺序为任务信息、成片视频、商品、抽帧产出图、生成任务链接；支持商品和任务检索、创建任务、高级设置及示例视频播放。

```sh
npm ci
npm run dev
npm run build
```

构建会生成单文件离线页 `dist/site/index.html`，已内嵌样式、脚本、图片和示例视频。可以直接打开，也可发布到静态网站。GitHub Actions 自动构建并发布此目录。

文档：[产品需求](docs/PRD.md)、[源码整理](docs/源码.md)。

这是前端交互原型。任务数据和成片为示例，新建任务只演示待生成状态，不连接后端生成服务。
