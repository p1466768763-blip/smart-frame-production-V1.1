# 智能抽帧生产 V1.1 PRD

## 1. 产品目标

为运营人员提供智能抽帧任务的创建、检索、参数配置与产出查看能力。用户将一批图片或视频素材关联到一个商品 ID，创建并启动抽帧任务；任务处理完成后，可按抽帧任务编号查看不同产出组的图片，并进入对应的生成任务链接。

## 2. 核心对象

### 2.1 生成任务

一次由用户发起的素材处理任务。每个生成任务只关联一个商品 ID，可以包含多个素材，并拥有唯一的生成任务 ID。

### 2.2 抽帧产出组

生成任务对素材完成抽帧后形成的一组图片排列。一次生成任务可以形成一组或多组抽帧产出，每组对应一条抽帧任务记录。

### 2.3 素材

创建任务时上传的图片或视频文件。一个生成任务可以包含多个素材。原型仅在浏览器本地读取文件，不向服务器上传。

### 2.4 商品

任务必须关联的业务对象。商品通过商品 ID 检索并单选，检索结果和已选商品均展示商品缩略图、商品 ID、店铺和商品类型信息。

## 3. 编号规则

### 3.1 生成任务 ID

- 格式：三位纯数字。
- 当前编号范围从 500 以上开始，原型示例使用 `501` 至 `510`。
- 新建任务从当前最大编号之后顺序递增，例如 `511`、`512`。
- 生成任务 ID 在全部任务中唯一。

### 3.2 抽帧任务编号

- 格式：`YYMMDD` + 当天第几次任务 + 当次任务产出的第几组排列。
- 全部字段连续展示，不使用连接符。
- 当天任务序号固定为两位，不足两位前补 `0`。
- 产出组序号固定为两位，不足两位前补 `0`。
- 示例：`2609090101` 表示 2026 年 9 月 9 日第 1 次抽帧任务产出的第 1 组排列。
- 同一次生成任务产出多组时，日期和当天任务序号保持相同，仅最后两位递增，例如 `2609090101`、`2609090102`。

## 4. 页面功能

### 4.1 任务列表

列表包含以下字段：

| 字段 | 逻辑 |
| --- | --- |
| 任务信息 | 合并展示抽帧任务编号和生成任务 ID，上方为产出组编号，下方为三位生成任务 ID，并保留批次展开、收起入口 |
| 成片视频 | 已完成示例任务展示可点击的视频封面，打开弹窗播放；新任务显示“待生成”。示例成片标识为“示例成片”，封面和视频内嵌于离线预览 |
| 商品 | 直接展示绑定商品的缩略图、商品 ID、店铺和类型信息，与创建任务时选择的商品保持一致 |
| 抽帧产出图 | 展示该产出组的图片缩略图与总数量 |
| 生成任务链接 | 任务完成后提供可点击的任务页面链接 |

列表最多保留 10 条原型数据。新建任务插入列表顶部，超出保留数量时移除末尾的示例行。

同一批抽帧任务按抽帧任务编号中的日期和当天任务序号分组，即编号除最后两位产出组序号之外的部分相同，则属于同一批。例如 `2609080101` 至 `2609080105` 属于批次 `26090801`。

- 默认折叠每一批任务，仅展示该批次的第一条任务。
- 有多条任务的批次，在第一条任务编号下方显示“展开同批 N 条”，N 为其余任务数。
- 点击展开后显示该批次的其余任务，入口变为“收起同批任务”；再次点击恢复为仅显示第一条。
- 各批次独立展开、收起；只有一条任务的批次不显示折叠入口。
- 同批首行使用稍深的中性色底，展开的同批任务使用更浅的底色；悬停时仍保持两类行的视觉区分。
- 搜索先筛选任务再分组，每批展示首条匹配记录；重新搜索时恢复折叠。
- 取消“序号”列，最左侧列为“任务信息”，合并展示抽帧任务编号与生成任务 ID。

### 4.2 任务检索

支持以下检索条件：

| 条件 | 规则 |
| --- | --- |
| 商品 ID | 允许输入完整或部分商品 ID，按包含关系匹配 |
| 生成任务 ID | 允许输入完整或部分 ID，按包含关系匹配 |
| 月份 | 选择任务所属月份 |

用户填写条件后点击“搜索”，列表按全部已填写条件组合筛选。条件为空时不限制对应字段。没有匹配结果时显示空状态。

### 4.3 创建任务

用户点击“创建任务”后打开创建任务弹窗。

创建任务必须完成以下两项：

1. 关联一个商品 ID。
2. 上传至少一个图片或视频素材。

只有两个条件都满足时，“确认创建并启动任务”按钮才可用。

确认后执行以下逻辑：

1. 创建新的生成任务 ID。
2. 创建该任务的第一条抽帧任务编号，产出组序号为 `01`。
3. 将新任务插入列表顶部。
4. 抽帧产出状态显示“正在抽帧”。
5. 生成任务链接状态显示“生成中”。
6. 关闭弹窗并显示创建成功提示。

### 4.4 商品关联

- 商品 ID 为必选、单选。
- 用户在常驻检索框中输入商品 ID，系统返回匹配商品。
- 检索结果的商品缩略图位于商品 ID 左侧。
- 用户选择商品后，在检索框下方显示“已关联”商品信息。
- 检索框选择商品后仍保持可用。
- 用户再次检索并选择其他商品时，新选择替换原已关联商品。
- 搜索结果下拉层级高于已关联商品信息，展开时不得被下方内容遮挡。

### 4.5 素材上传与预览

- 支持图片和视频文件。
- 支持一次选择多个文件。
- 首次上传完成后，上传区域切换为素材文件夹视图。
- 素材以等比例缩略图展示，视频缩略图显示播放标识和文件名。
- 点击缩略图可打开图片或视频预览。
- 素材网格末尾始终显示与缩略图同尺寸的虚线“继续上传”入口。
- 继续上传会追加文件，不覆盖已选择的文件。
- 素材数量较多时，弹窗内容区允许滚动。

### 4.6 抽帧产出图

- 每个单元格采用三列缩略图排列。
- 单元格同时最多显示 6 张图片，即两行。
- 超出 6 张的图片通过单元格内部纵向滚动条浏览。
- 缩略图采用打乱后的固定排列顺序，页面重新渲染时顺序保持稳定。
- 单元格右上角显示总产出图片数量，例如“198 张”。
- 数量代表任务实际产出的图片总数，不等于当前可见的示意缩略图数量。

### 4.7 高级设置

用户点击“高级设置”后打开大弹窗，可配置抽帧策略和输出参数。

抽帧策略为单选：

| 策略 | 逻辑 |
| --- | --- |
| 智能采样 | 自动识别画面变化并选择代表帧 |
| 固定间隔 | 按用户设置的秒数均匀抽帧 |
| 关键帧优先 | 优先保留画面变化明显的关键帧 |

输出参数包括：

| 参数 | 规则 |
| --- | --- |
| 抽帧间隔 | 数字，单位为秒，最小步进 0.5 秒 |
| 每个视频最多抽取 | 正整数，限制单个视频最大抽帧数量 |
| 图片质量 | 单选：标准、高清、原图 |

点击“保存设置”后保存当前参数、关闭弹窗并显示保存成功提示。点击“取消”或关闭按钮时不应用本次修改。

### 4.8 生成任务链接

- 任务处理完成后展示可点击的网页链接。
- 点击后在新标签页打开任务页面。
- 任务创建后、链接尚未生成时显示“生成中”。

## 5. 状态定义

### 5.1 任务状态

| 状态 | 抽帧产出图列 | 生成任务链接列 | 可执行操作 |
| --- | --- | --- | --- |
| 创建中 | 正在创建 | 生成中 | 查看列表 |
| 抽帧中 | 正在抽帧 | 生成中 | 查看列表 |
| 已完成 | 图片缩略图、数量徽标 | 可点击链接 | 浏览产出、打开链接 |
| 失败 | 抽帧失败及失败提示 | 不可用 | 查看失败原因、重新创建任务 |

原型当前演示“抽帧中”和“已完成”两种状态。

### 5.2 创建弹窗状态

| 状态 | 表现 |
| --- | --- |
| 未选择商品、未上传素材 | 确认按钮禁用 |
| 已选择商品、未上传素材 | 确认按钮禁用 |
| 未选择商品、已上传素材 | 确认按钮禁用 |
| 已选择商品、已上传素材 | 确认按钮可用 |
| 商品检索中 | 展示匹配结果下拉列表 |
| 已关联商品 | 展示已关联商品卡片，仍可继续检索并替换 |
| 已上传素材 | 展示素材文件夹视图和继续上传入口 |

## 6. 交互反馈

- 搜索成功后提示筛选条件已应用。
- 创建任务成功后提示新任务编号。
- 高级设置保存后提示当前策略已保存。
- 导航中的非当前页面作为原型占位，点击后提示该入口为导航示意，当前页面保持不变。
- 商品未匹配时提示用户检查商品 ID。
- 图片或视频预览支持通过关闭按钮退出。
- 弹窗支持取消操作，取消后不创建任务。

## 7. 原型数据与持久化

- 当前原型为纯前端示意，没有后端接口。
- 新建任务、筛选条件、高级设置和已选择文件仅保存在当前浏览器页面状态中。
- 刷新或重新打开 HTML 后，状态恢复为初始示例数据。
- 示例生成任务链接使用 `example.com`，仅用于表达链接行为。
